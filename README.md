# AutoTrzcina (Fabric 1.21.4, mod klientowy)

Automat farmy trzciny: klika Twój przycisk, chodzi do ustawionych miejsc,
zbiera trzcinę i sprzedaje ją pod /sklep. Chodzenie robi mod **Baritone**.

## Klawisze
- O - menu
- G - start / stop

## Ustawianie (raz)
1. Stań przy przycisku, otwórz menu (O) -> "Pozycje" -> kliknij "Stoję przy przycisku".
2. Patrz na przycisk -> kliknij "Przycisk (patrz na niego)".
3. Stań tam, gdzie spada trzcina -> "Miejsce zbierania".
4. (opcjonalnie) stań w miejscu sprzedaży -> "Miejsce sprzedaży".
5. Zakładka "Czasy": co ile klikać i ile czekać na trzcinę.
6. Zakładka "Sklep": komenda i sloty (włącz "Pokaż numery slotów", wejdź do /sklep).
7. G - start.

## Mody w folderze mods
Fabric API + Baritone (fabric, 1.21.4) + ten mod.
